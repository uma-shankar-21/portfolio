# Uma Shankar Kommireddy — Portfolio

A responsive, single-page portfolio built with React, TypeScript, and Vite. The content focuses on applied AI, full-stack engineering, quality engineering, and three verified GitHub projects.

## Run locally

```sh
npm install
npm run dev
```

Create and preview the production build:

```sh
npm run build
npm run preview
```

## Public documents

- `public/Uma_Shankar_Resume.pdf` is used for the view and download resume actions.
- `public/Uma_Shankar_hackthn_cert.pdf` is used for the view and download certificate actions. The certificate documents participation; the finalist selection details are stated separately from the resume.

The contact form opens a prefilled `mailto:` message and does not require a backend.
